# 🧋 Boba Bobyyy

A cozy boba shop game that runs in the browser. Take orders, make drinks, keep customers happy, and grow your shop.

**▶ Play it here: https://faribaislam-spec.github.io/boba-shop/**

## How to play

- Customers line up at the counter with their order in a speech bubble.
- Build the drink by choosing a base, milk, sugar, topping and ice, then hit **Serve**.
- Serve the highlighted customer before their patience bar runs out.
- Named drinks follow a recipe (open the **📖 Menu** or press **M**). Purple bubbles are custom orders, so follow their list.
- Each shift lasts 3 minutes. Earn coins and XP, level up, and buy new ingredients in the **🛒 Shop** to unlock new recipes.

## Features

- Animated drink making: tea pours in, syrup rises, pearls drop, ice floats
- Customer queue with patience bars and mood faces
- Named recipes and custom orders
- XP, levels, and a level-up popup
- Ingredient shop with level-gated unlocks
- High score and progress saved in the browser

## Built with

Plain HTML, CSS and JavaScript. No frameworks or libraries.

## Run it locally

Download or clone the repo and open `index.html` in any browser.
